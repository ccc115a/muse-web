LLM & TinyTransformer 原始碼對照與原理解析

本教材結合 `llm-tf` 專案中的實際 JavaScript 程式碼（`tf0/engine.js` 與 `llm/finetune.js`），以左側觀念與右側原始碼對照的方式，呈現大語言模型的底層架構。

1. Token 化（Tokenization）與 One-Hot 編碼

神經網路無法直接運算純文字，必須將文字轉換為離散數值（Token ID）或 One-Hot 向量。在本專案中，我們為語料建立單一字元字典（`stoi` 與 `itos`）。

底層映射流程

  • 字元 ➔ ID：例如 "火" ➔ 24, "星" ➔ 78。
  • tf.oneHot 轉換：將 ID 轉為高維度的 0/1 向量，便於與 Embedding 權重矩陣做乘法提取。

🛠️ 互動：即時 Token 化轉換

// 1. tf0/engine.js 中的 One-Hot 前向算子
function oneHotForward(indicesData, indicesShape, depth) {
  const size = indicesData.length;
  const out = new Float32Array(size * depth);
  for (let i = 0; i < size; i++) {
    const idx = indicesData[i];
    if (idx >= 0 && idx < depth) out[i * depth + idx] = 1;
  }
  return { data: out, shape: [...indicesShape, depth] };
}

// 2. llm/finetune.js 中取得 Token Embedding
const tokenOneHot = tf.oneHot(tokenIds, this.vocabSize)
  .toFloat().reshape([batchSize * time, this.vocabSize]);
const tokenEmbeddings = tokenOneHot.matMul(this.tokenEmbedding);

2. Token Embedding 與 Positional Embedding 疊加

矩陣乘法 tokenOneHot.matMul(tokenEmbedding) 等同於在 [VocabSize, Dim] 矩陣中查表提取對應特徵列。

位置資訊（Positional Embedding）

因為 Transformer 的自注意力運算本身無視字符的前後順序，因此必須另外建立 positionEmbedding [SeqLen, Dim] 矩陣，並將位置特徵相加至 Token 特徵中。

📐 矩陣維度演變說明

  • tokenIds: 形狀 [1, 16] (16 個字符)
  • tokenEmbeddings: 形狀 [1, 16, 32] (32 維隱藏層向量)
  • x = tokenEmbeddings + positionEmbeddings: 形狀仍為 [1, 16, 32]
源碼檔: llm/finetune.js (TinyTransformer) Embedding 向量疊加 
// 定義變數矩陣 [VocabSize, 32] 與 [SeqLen, 32]
this.tokenEmbedding = variable([vocabSize, this.dim]);
this.positionEmbedding = variable([seqLen, this.dim]);

// 讀取位置向量與詞向量
const positionOneHot = tf.oneHot(tf.range(0, time, 1, 'int32'), this.seqLen).toFloat();
const tokenEmbeddings = tokenOneHot.matMul(this.tokenEmbedding);
const positionEmbeddings = positionOneHot.matMul(this.positionEmbedding);

// 向量相加融入位置特徵
let x = tf.add(tokenEmbeddings, positionEmbeddings);

3. Multi-Head Self-Attention 與 Causal Mask

輸入特徵 x 分別乘以 Wq, Wk, Wv 矩陣得到 $Q, K, V$。透過多頭切分（4 Heads），模型能在不同的子空間關注文字關聯。

因果遮罩（Causal Mask）

預測未來字詞時，為了防止模型偷看解答，矩陣右上角填入 $-10^9$。經由 Softmax 後該處權重精準歸零。

👁️ 互動：4-Head 注意力矩陣熱圖

源碼檔: llm/finetune.js & tf0/engine.js Self-Attention 算式 
// 計算 Q, K, V 並切分成 4 個 Head
const q = reshapeHeads(flat.matMul(this.wq));
const k = reshapeHeads(flat.matMul(this.wk));
const v = reshapeHeads(flat.matMul(this.wv));

// Scores = (Q · K^T) / sqrt(d_k) + Mask
const scores = tf.matMul(q, k, false, true)
  .div(Math.sqrt(this.headDim))
  .add(this.mask.slice([0, 0], [time, time]));

// Attended = Softmax(Scores) · V
const attended = tf.matMul(tf.softmax(scores), v);

4. Transformer 前向傳播與 Logits 輸出

經過 Self-Attention、殘差連接（Residual Connection）與前饋神經網路（FeedForward）後，最終隱藏向量乘以 tokenEmbedding 轉置矩陣，還原為詞表大小的 Logits 分佈。
