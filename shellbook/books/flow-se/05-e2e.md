# 第五章：Playwright 端到端測試

單元測試證明零件是好的，E2E 證明整台車會動：Playwright 開真實瀏覽器，從使用者角度走完新增 → 勾選 → 重整 → 刪除。接續前面的 shell 狀態（`/tmp/flowboard`）。

先確保環境就緒（等冪，重複執行無害）：

```shell
[ -d /tmp/flowboard/e2e ] || { if [ -z "$FLOW_BOOK" ] || [ ! -d "$FLOW_BOOK/examples/flowboard" ]; then _d="$PWD"; while [ "$_d" != / ] && [ ! -d "$_d/examples/flowboard" ] && [ ! -d "$_d/books/flow-se/examples/flowboard" ]; do _d=$(dirname "$_d"); done; if [ -d "$_d/examples/flowboard" ]; then export FLOW_BOOK="$_d"; elif [ -d "$_d/books/flow-se/examples/flowboard" ]; then export FLOW_BOOK="$_d/books/flow-se"; else export FLOW_BOOK=$(find /Users/Shared "$HOME" -maxdepth 8 -type d -path '*shellbook/books/flow-se' 2>/dev/null | head -1); fi; unset _d; fi; echo "FLOW_BOOK=$FLOW_BOOK"; rm -rf /tmp/flowboard && cp -r "$FLOW_BOOK/examples/flowboard" /tmp/flowboard; }
cd /tmp/flowboard/e2e && cat package.json
```

預期輸出：

```text
{
  "name": "flowboard-e2e",
  "version": "0.1.0",
  "private": true,
  "description": "flowboard 端到端測試",
  "scripts": {
    "setup": "npx playwright install chromium --only-shell",
    "test": "npx playwright test"
  },
  "devDependencies": {
    "@playwright/test": "^1.49.0"
  }
}
```

## 建置受測系統（release 版後端 + 前端 dist）

E2E 測的是接近正式環境的組合，所以用 release 建置：

```shell
cd ../backend && cargo build --release 2>&1 | tail -1 && cd ../frontend && npm run build >/dev/null 2>&1 && ls dist/ && cd ../e2e
```

預期輸出：

```text
Finished `release` profile [optimized] target(s) in 1.85s
app.js
index.html
style.css
```

## 跑 E2E（Playwright 自動拉起後端）

`playwright.config.js` 的 `webServer` 會自動啟動 release 版後端、測完自動關掉：

```shell
npx playwright test 2>&1 | tail -6
```

預期輸出：

```text
Running 3 tests using 1 worker

  ✓  1 tests/board.spec.js:12:1 › 新增任務後出現在列表 (610ms)
  ✓  2 tests/board.spec.js:19:1 › 勾選完成會跨重整保留 (326ms)
  ✓  3 tests/board.spec.js:28:1 › 刪除任務 (306ms)

  3 passed (4.0s)
```

## 手動模式：自己啟 server 再測

想看瀏覽器實際操作過程，用 `--headed`（需要有螢幕環境）：

```shell
PORT=3001 FRONTEND_DIR=../frontend/dist DATA_FILE=/tmp/fb-e2e.json ../backend/target/release/flowboard & sleep 1
```

預期輸出：

```text
flowboard listening on 0.0.0.0:3001
```

```shell
NO_WEBSERVER=1 npx playwright test --reporter=line 2>&1 | tail -4; kill %1 2>/dev/null; rm -f /tmp/fb-e2e.json
```

預期輸出：

```text
[1/3] tests/board.spec.js:12:1 › 新增任務後出現在列表
[2/3] tests/board.spec.js:19:1 › 勾選完成會跨重整保留
[3/3] tests/board.spec.js:28:1 › 刪除任務
  3 passed (2.3s)
```

## 看測試報告

```shell
ls playwright-report 2>/dev/null || NO_WEBSERVER=1 npx playwright test --reporter=html >/dev/null 2>&1; ls playwright-report/ 2>/dev/null | head -3
```

預期輸出（HTML 報告已產生，用瀏覽器開 `playwright-report/index.html` 可看）：

```text
data
index.html
```

## 重點回顧

- E2E 對應需求的驗收標準：測試即文件
- `webServer` 讓測試自包含：CI 不用手動啟服務
- 單元測試快、E2E 慢：金字塔下寬上窄，E2E 只覆蓋關鍵路徑
