# git 實戰：從 init 到協作

一本教你 git 的書：從 init 到 push，全程本地演練，不用上 GitHub 也學得會。點超連結進任意一章開始學，不用從頭。

## 目錄

- [第一章：環境檢查](ch01-setup.md) — 確認 git 在、清出場地。
- [第二章：第一次 commit](ch02-first-commit.md) — 建倉、寫檔、commit、看歷史。
- [第三章：分支與合併](ch03-branch-merge.md) — 開分支合併，再故意衝突、解決衝突。
- [第四章：遠端協作（本地模擬）](ch04-remote.md) — 本地 bare 當遠端，push 上去再 clone 下來驗證。
