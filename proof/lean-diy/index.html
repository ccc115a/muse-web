Mini-Lean 純前端證明系統

相依型別 kernel＋tactic 引擎全部跑在瀏覽器裡（ES 模組，無後端）。先用 npm run serve 啟動靜態伺服器再開啟本頁。

就緒
tactic速查表（點開）
tactic說明
intro x y引入 ∀/→ 的前件
exact e用證明項 e 直接結案（含 ⟨a, b⟩ 匿名建構子）
apply e用引理 e 化簡目標（結論須唯一決定參數）
assumption / trivial在假設中找證明 / 簡易自動結案
rfl定義相等（會計算，如 2 + 3 = 5）
constructorAnd 拆成兩個子目標；True 直接結案
left / rightOr 選左/右
cases h with a b拆解 And / Or / Exists / False / Eq / Nat
induction n with k ih對 Nat 歸納（base / step）
rw [h1, <- h2]用等式改寫目標（自動試 rfl 收尾）
simp / simp [lem] / simp only [lem]化簡（內建 Nat/Prop 引理＋fixpoint）
have h : T := e / … := by …加入中間引理
show T換成定義相等的目標
· tac / case tag => tac; tac / all_goals tac子目標聚焦（每行預設作用於第一個子目標；; 廣播到全部）
sorry暫時承認（會警告並記錄為公理）

宣告：theorem 名 (x : T) : P := by …（lemma/example/def/axiom 亦可）；#check e、#eval e 可印型別與求值。

輸出

按「▶ 執行」檢查編輯器中的證明。每個證明項都會被可信 kernel 重新檢查。

Node.js 測試：npm test（kernel＋parser＋tactics＋全部範例＋前端靜態檢查）
