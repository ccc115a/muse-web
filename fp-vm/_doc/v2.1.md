# v2.1 — Array（原生 TAG）+ structure（純 desugar）

版本狀態：完成。新範例雙端 SAME，全量六腳本 PASS。

## 1. Array：新 TAG.ARR = 12

* **表示**：`fpvm` 用 `Arr` 包裝類；wasm 線性記憶體 `[ARR][len][elems...]`。
  `toStr` 雙端統一印 `#[1, 2, 3]`；`equal` 逐元素（含跨型別數值相等）。
* **語意**：persistent——`set` 全拷貝 O(n)，舊 array 不變（已測）。
  結構共享未做（有效能投訴再說）。
* **prims**（`PRIM_NAMES` 附加 7 個，舊 ID 不動）：`array`（變元建構）、
  `array-empty`、`array-push`、`array-get`、`array-set`、`array-size`、`array?`。
  arity 一律精確檢查（雙端同訊息）；越界 / 型別錯誤走 `THROW` 可 catch，
  訊息雙端逐字一致（含長度與索引值）。
* **表面**：`#[1, 2, 3]`、`#[]`（`#` + `[` 另立 token，不吃 `#eval` 規則）。
  `#[...]` 降為 `(array e...)` runtime 建構，不經 CONST。
* **Lean 別名**：`-` 進不了 Lean 識別字，連字號 prim 用本名別名——
  `Array.size/push/get/set/empty`（`Array.empty` 備而少用；`#[]` 為主）。
  `array?` 無連字號，直用。
* **不做**：`map/filter` 高階（v2.4 prelude）、slice、結構共享；
  `length/append` 不吃 array（請用 `array-size`，`length` 遇 array 得 0 的舊寬容保留）。

## 2. structure：純 desugar，VM 零改動

* `structure Point where` + 欄位行 → 單 ctor inductive（內部 `ctor/Point.mk`）
  + 每欄一個投影 `def Point.x`（match 取欄，錯型別給 `Match_failure` 而非垃圾值）。
* `{ x := 1, y := 2 }`：按欄位集合找唯一 structure（多/無匹配皆報錯），
  依**宣告順序**排成 ctor 應用（書寫順序可亂）。
* `{ p with x := 3 }`：未動欄位自動補投影讀值；基底限純變數。
* **限制**（都會報清楚的錯）：structure 請先宣告再使用（`{...}` 需 parse 期欄位表；
  `Point.mk` 表達式可前向，靠 pre-scan）；`extends` 不做；`p.x` 點記法不支援
  （無型別資訊，請寫 `Point.x p`）；欄位名禁保留字。

## 3. 附帶：`try` 表面 + `mlc` 新節點

* `leanc` 新增 `try BODY catch VAR => HANDLER`（單一 catch；`catch` 升為關鍵字）。
  有了它，`Match_failure` 與 array 越界在 Lean 側也可 catch（補上 v2.0 驗收缺口）。
* `mlc` 新增 AST 節點（parser 不變，只給 `leanc` 用）：
  `{t:'call', f, args}` 直接多參呼叫（給 `array` 等變元 prim；注意不可 curry），
  `{t:'try', body, var, handler}`。`mlc` 另把 5 個 array prim 登入 `PRIM_ARITY`
 （`array` 變元、`array-empty` 0 元不入表）。
