# v2.3 — 字串/Char 完整化 + `UInt*` + IO 擴充

版本狀態：完成。`lean/07/08/09` 雙端 SAME，全量六腳本 PASS。

## 1. 字串/Char

* 單位統一為 Unicode scalar（`string-length` 舊為 UTF-16 單位，BMP 相同、
  astral 才差；suite 驗證無回歸）。
* 新 prim（雙端，同訊息）：`string-ref`（越界 THROW）、`substring`
  （左閉右開，越界/倒置 THROW）、`char->nat`、`nat->char`
  （0..0x10FFFF 扣代理區，否則 THROW）；別名 `String.get`、`String.extract`、
  `String.length`、`Char.toNat`、`Char.ofNat`。
* `<`/`>`/`<=`/`>=` 支援雙字串（字典序；混型別維持型別錯誤；小整數仍走 `F_FAST`）。
* Char 字面量即 codepoint Nat：`'a'`、`'\n'`、`'\\'`、`'\''`、`'\u{1F600}'`
  （lexer 直吐 BigInt num token，parser 零改動）；`'ab'` 報錯。

## 2. `UInt*`：3 prim + 自舉 prelude

* 新 prim（雙端，bigint 精確，JS BigInt 語意一致）：`bit-and`、`bit-or`、
  `bit-xor`（別名 `Bit.*`；`not` 用 xor-mask 代，不另開 prim）。
* 其餘全是 Lean 寫成的 baked prelude：`pow2`、`Nat.pow`、通用
  `uMask/uNorm/uAdd/uSub/uMul/uDiv/uMod/uShl/uShr/uAnd/uOr/uXor/uNot/uToNat/uFromNat`
 （輸入一律先 mask 正規化；除零顯式 guard 走 `error`），加
  `UInt8/16/32/64` 全套 thin wrapper（各 13 個一行 def，`def UInt32.add...`
  連帶打通了 dotted def/呼叫）。
* 附帶：`def` 名保持全名（`UInt32.add` 可定義可呼叫）；用戶 `def` 禁 `__` 前綴
  與 prelude 名（防靜默劫持）；`USize`、有號 `Int` 不做。

## 3. IO：`read-line`、`get-args`、`exit`

* `read-line ()` 首調讀光 stdin（尾換行不算空行；TTY 直接回 nil 不卡住），
  每調吐一行，EOF 回 nil。**stdin 具消耗性，不可進比對 harness，手測。**
* `get-args ()` 回程式檔之後的參數列；`exit code` 停機（專用異常直通，
  不可 catch；`fpvm` CLI 設 `exitCode` 自然收尾，wasm 經 worker 回報 `{exit}`，
  in-process 往外拋）。
* 0 元 prim 取「忽略 `()`」慣例（同既有 `newline ()`）；別名 `IO.readLine`、
  `IO.getArgs`、`IO.exit`。`prog.wasm` CLI 用 `--` 後接程式參數；
  `runBytes(bytes, args=[])` 加參（預設相容）。
* 不做：`eprint`、`file-read/write`、互動式輸入。

## 4. 範例與驗收

`09_io`（空參數列 + 結尾 `exit 0` 可進 harness；read-line/帶參/非零碼手測通過）。
