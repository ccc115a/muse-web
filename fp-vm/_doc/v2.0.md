# v2.0 — 微型 Lean 前端（`leanc.js`），新語言的基礎

> 自此版起以 Lean 語面為基礎發展新語言：後續版本（Array、結構、typeclass 等）
> 都在這條線上加，不再回頭擴充 ML 線。

版本狀態：原型完成。三範例 VM / wasm 雙端輸出一致（`run_lean.sh` 全過）。

## 1. 這版是什麼

Lean 風格表面語法 → `.fbc` 的第四個前端（前三個：`lispc`、`lambdac`、`mlc`、`cljc`）。
刻意不做 elaborator：無 dependent unification、無 tactic、無完整 typeclass 推論，
型別全部擦除（Prop / 證明項在 runtime 不存在）。能成立的原因：Lean 求值是 eager
的，且證明可擦除——整條路比 Haskell 前端容易，難度約等於 mini-ML + Nat。

## 2. 工具鏈位置

```
*.lean --(leanc parser)--> mlc AST --(mlc Desugar)--> Scheme --(lispc)--> .fbc
                                                                              ├─→ fpvm.js
                                                                              └─→ vm2wasm.js
```

* `leanc.js`：自有 lexer / parser，只產 **mlc AST**，後段完全複用 `mlc`。
* 為此 `mlc.js` 配合改了三處：匯出 `Desugar`、`show` 支援 bigint（自動補 `N`
  後綴給 `lispc`）、新增 `begin` 節點（ml 測試重跑全過，無回歸）。

## 3. 用法

```
node leanc.js prog.lean [-o prog.fbc]     編譯（預設輸出同名 .fbc）
node leanc.js prog.lean --scheme          只印 Scheme 核心，除錯用
node leanc.js prog.lean -o -              輸出到 stdout
node fpvm.js prog.fbc                   JS 虛擬機執行
node vm2wasm.js prog.fbc [--run]          轉 wasm / 執行
sh run_lean.sh                            三範例雙端比對
```

## 4. 語言範圍（v1）

| 支援 | 說明 |
|---|---|
| `inductive`（非依賴） | `\| Ctor` / `\| Ctor (T) (T)`，欄位數 = 括號群個數，型別內容忽略；`deriving` 跳過 |
| `def` 單體 | `def f (x : Nat) : Nat := ...`，`( )` 為顯式參數，`{ }`/`[ ]` 整組略過，`: Ret` 跳過 |
| `def` 多方程式 | `def f : T \| 0 => .. \| n => ..`，函式名前綴可省略；多參數用逗號（`\| .nil, ys =>`）；單參直接 `match`，多參先包 tuple |
| `abbrev` | 同 `def` |
| `#eval e` | 求值並印出（`display` + 換行） |
| `match [h :] e with` | 含可選 `h :` 前綴；scrutinee 可逗號並列（自動包 tuple） |
| `if [h :] c then a else b` | 證明參數 `h` 擦除 |
| `let x := e; body` | term-let；do 內 `let x := e` / `let x ← e` / `x ← e` |
| `fun x => e` | 單參數（可多個連寫）；pattern 參數沿用 mlc 形狀 |
| `do` | 見 §5；`return e` 即 `e` |
| `import/open/namespace/section/end/variable/universe` | no-op（跳過該行） |
| 字面量 | 十進位整數一律 BigInt（Nat）；`3.14` 浮點；`"..."`；`true/false`；`()` 兼 unit/nil；`[e, ...]` 原生 list |
| 註解 | `--` 行註解、`/- -/` 可巢狀區塊註解 |
| 運算子 | `+ - * / % = == != < > <= >= :: && \|\|`，`+` 結尾的 `?`/`!` 名稱（`head?`） |

| 不支援（遇到給清楚報錯） | 原因 |
|---|---|
| `structure/class/instance` | 字典請手動傳 |
| `theorem/lemma/example` | 證明不在 micro 範圍 |
| tactic（`by ...`）、`where` | 同上 |
| `Nat.succ n` pattern | Nat 是 primitive bigint，只能比對字面量 / 變數 |
| `#[...]`、`'c'`、字串插值 | 未實作表面語法 |
| 完整 typeclass、Array、`UInt*` | 見 §7 後續 |

## 5. 語意決策（與 Lean 取齊之處，以及取巧之處）

* **Nat 語意**：`/` = 截斷除法（`quotient`），`%` = `modulo`，`-` = 截斷減法
  （`3 - 5 = 0`，以 `if (< a b) 0 (- a b)` 實現）。`7 / 2 = 3` 已驗證。
* **do 取 direct-style IO**：`println` 即印出，`←` 即 `let`，無真正 monad 值。
  `main`（無參數）定義即自動執行。
* **do 分隔規則**：動作以換行/`;` 分隔，以頂層關鍵字、`|`（match arm）、`)]}`
  或 EOF 收尾；並置跨行需比動作縮排更深，否則判為下一個動作。
* **點名**：`NatList.cons` / `.cons` 取最後一段；建構子內部一律 mangle 為
  `ctor/名`（故 Lean 風格的 `nil` 可用；`true/false` 禁作建構子名，與字面量衝突）。
* **隱式參數** `{x}` / `[inst]` 整組略過（定義與呼叫兩端一致，micro 世界自洽）。

## 6. 範例與預期輸出

`lean/01_nat.lean`（多方程式、截斷語意）：`fact 20`、`fib 20 = 6765`、
`isEven`、`1000000 - 1 = 999999`、`7 / 2 = 3`。

`lean/02_list.lean`（inductive + match + 多參數方程式）：`sum = 6`、`len = 3`、
`append`、`head?`（空表回 0）、巢狀 pattern 的 `classify`。

`lean/03_io.lean`（do / let / ← / main）：

```

50
```

## 7. 已知 deviation（v1 接受，後續處理）

1. 輸出顯示 `ctor/` 前綴（如 `(ctor/cons 1 ctor/nil)`）——內部名外洩，待美化（類 `Repr`）。
2. `-` / `/` 取 Nat 語意：浮點與 Nat 混用會報錯（`3.5 - 5` 得 `<: 需要整數`，
  因截斷實現先經整數比較），浮點請勿混入 Nat 運算。
3. `[]` 是原生 list，不是 ADT——ADT 串列請手寫 `.cons`。
4. 方程式與顯式參數不可並存；方程式各分支參數個數須一致；0 參數方程式不接受。
5. 單行 `let x := e`（無 `; body`）只在 do 內合法。
6. 後續：Array 新 TAG（要 O(1) 才有意義）、`UInt*` wraparound prim、讀檔 IO、
   `structure`、完整 typeclass、`Nat.succ` pattern。

* 全量回歸：`run_clj.sh`、`run_lc.sh`、`run_lisp.sh`、`run_ml.sh`、`run_wasm.sh`
  皆 PASS（`mlc` 的 `begin` / `Desugar` 匯出無回歸）。
