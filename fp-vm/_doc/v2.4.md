# v2.4 — 標準函式庫起步 + `Monad` + `do[M]`

版本狀態：完成。`lean/07_monad.lean` 雙端 SAME，全量六腳本 PASS。

## 1. 只 bake 函式，不 bake 型別（關鍵抉擇）

`Option`/`Except` 型別、`Monad` class、實例全部由用戶宣告（範例 07 約 10 行）。
prelude 只多 14 個 plain def（`List.*`、`Option.*`、`Except.*`）。
理由：bake 型別要處理「重複宣告形狀比對」一整類麻煩；且 `List.*` 只要求
cons/nil 標籤存在（全範例本來就有），缺了是清楚的 unbound錯而非靜默錯。
`List` 型別本身不 bake（避開與用戶 `NatList` 的名字糾纏）。

## 2. `do[M]` 語意

* `do [M] ...`（`M` 為型別名）：`x ← e` 降為 `bind`；`let` 維持純綁定；
  一般動作逐個 bind；`return e`/`pure e` 查 `(Monad, M)` 型別列
  （`pure` 沒東西可分派，這是唯一解；裸 `pure` 在 block 外仍走值分派，多半落空）。
* 無註記 `do` 維持 direct-style；monadic block 結尾須為 expr（尾 `let`/`←` 報錯）。
* 巢狀 do 各自獨立（monad 放區域變數）。
* predicate 真值沿用 lisp 語意（僅 `#f` 為假；`nil` 算真，predicate 請回 Bool）。

## 3. prelude（自舉，同一 parser）

* `List.map/filter/foldl/length/append/reverse(+Aux)`：吃任何 cons/nil-tagged ADT。
* `Option.map/bind/getD`、`Except.map/bind/getD/toOption`。
* `def` 保留機制自動保護 prelude 名；dotted def（`List.map`）可定義可呼叫。
* `pure`/`bind` 方法名、`Option` 等型別由用戶宣告，無內建魔法
  （`List.map` 的 `f` 為閉包參數；`filter` 續行縮排規則照舊）。

## 4. 不做

* `List` 型別本身、`Monad` 內建實例（用戶寫，範例即模板）。
* transformer（`StateT` 等）、多參數 class（沿用 v2.2）。
* `pure` 高階傳值、裸 `pure` 的友善報錯（目前是 unbound）。
* `orElse`（eager 語意易誤解；`getD` 已覆蓋預設值需求）。

## 5. 範例與驗收

（`err 99` 跳過後續）、`List.map`/`length`、`getD`、`toOption`；雙端 SAME。
落空（無 instance 的 `pure`、未註冊標籤）雙端同訊息。
