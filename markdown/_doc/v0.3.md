## 專案資訊面板（頂欄「專案資訊」）

- 非 git 目錄／相容模式：直接說明原因。
- 本機區：目前分支（或 detached）、最後 commit（SHA＋subject＋作者＋日期；
  commit 在 packfile 內只顯示 SHA）、分支一覽、remotes 表。
- GitHub 區（remote 是 github.com 才有）：repo 連結＋簡介＋stars＋預設分支、
  最近 5 次 Actions（✅/❌/⏳＋分支＋SHA＋時間＋連結）、Pages 站點連結＋設定連結。
  私人 repo 或額度用完 Loretta 只顯示連結＋原因。

## 去 prompt 化

  之後直接編輯存檔。
- 新增檔案／資料夾、重新命名、刪除、關閉未存檔分頁：全部改 `modal.js` 自繪對話框。
- 原始碼 `prompt(`/`confirm(` 歸零（grep 驗過）。
