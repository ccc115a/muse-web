# MD Editor v0.2（基於 v0.1）

新增：把已開啟資料夾一鍵轉成 gh-pages 靜態網站，並自動產生 GitHub Action。

## 新增內容

```
packages/core/src/site.mjs     # 純函數：路徑映射、標題、nav、站點頁模板、Action YAML
packages/core/test/site.test.js # 6 tests
apps/web/src/site-export.js    # 遍歷、轉檔、寫入 site/（native）或 zip 下載（fallback）
apps/web/src/main.js           # 「發佈靜態網站」按鈕＋流程
apps/web/index.html            # 同上按鈕
```

## 產出（假設開啟的資料夾即 repo 根目錄）

```
<repo>/site/                        # 站點：每 .md 一頁 HTML（左導覽＋同 renderer 內文）
<repo>/site/index.html              # 根 README.md 優先，否則頁面清單
<repo>/site/.nojekyll
<repo>/.github/workflows/gh-pages.yml  # 官方 Pages Action（checkout→upload artifact→deploy）
```

- 非 md 檔（圖片等）原樣複製，二進位逐位元組保留。
- 跳過：`.` 開頭、`node_modules`、`dist`、`.git`、輸出目錄本身。
- 相容模式（Firefox/Safari）：改下載 `<root>-site.zip`，內含同樣結構＋Action 檔，解壓進 repo 根再 push。

## 上線步驟（使用者在 VSCode 做）

1. 本站按「發佈靜態網站」（輸出目錄預設 `site`，分支預設 `main`）。
2. VSCode 裡 `git add/commit/push`。
3. repo Settings → Pages → Source 選「GitHub Actions」→ 開 `https://<owner>.github.io/<repo>/`。

## 驗證

- `npm test`：core 20/20（新增 site 6 tests）
- `site-export.js` node 端到端（virtual 節點）：收集跳過正確、katex/mermaid/alert 具在、
  code 內 `$` 保留、深層頁面回根連結正確、首頁用 README、圖片位元組一致、`.nojekyll` 具在
- `vite build` 過；Webview＋vsix（3.42MB）同步重建；`dist/` 含發佈按鈕

## 已知簡化／限制

- 開啟的資料夾必須就是 repo 根（否則 Action 路徑要手拿過去）。
- 分支寫死為 prompt 預設 `main`，其他分支名手改 yaml。
- 站點頁的 mermaid/KaTeX 走 CDN，需連網。

## 修補（發佈失敗 Name is not allowed）

- 輸出目錄先經 `sanitizeOutDir` 正規化（`site/`→`site`，擋空／`..`），支援巢狀如 `docs/site`；
  收集階段改前綴比對跳過輸出目錄。
- 寫入前清空舊輸出；單檔失敗記下繼續，最後一次列出（錯誤訊息帶完整路徑，不再是裸錯誤）。
- 新增檔案／資料夾名稱亦擋斜線與 `.`／`..`。
