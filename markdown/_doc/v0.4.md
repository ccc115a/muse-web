# MD Editor v0.4（基於 v0.3）

發佈來源可選子資料夾（之前只能整包 `/`）。

## 變更

```
packages/core/src/site.mjs      # 新增 sanitizeSrcDir（'' 或 '/' 表根）
apps/web/src/site-export.js     # collectFiles/buildSiteFileMap 吃 srcNode；新增 listDirs（來源選擇器用）
apps/web/src/modal.js           # 新增 formModal（text/select/checkbox）
apps/web/src/main.js            # 發佈流程：來源下拉＋輸出/分支＋「記住」核取，存回 .mdeditor.json
apps/web/src/project.js         # defaultConfig 加 srcDir: ''
```

## 行為

- 「發佈靜態網站」彈出站內表單：來源下拉（`/`＋遞迴子目錄清單）、輸出目錄、分支、記住核取。
  全程無 `prompt()`。
- 來源相對路徑換算：輸出目錄過濾改「來源相對」前綴比對（repo 根 `site/` 不會污染子目錄發佈）。
- 子目錄發佈的首頁：該目錄下根 `README.md` 優先，否則頁面清單。
- `.mdeditor.json` 形狀：`{ srcDir, siteDir, branch }`。

## 驗證

- `npm test`：core 29/29（新增 sanitizeSrcDir）
- node 端到端（virtual 節點）：子目錄只收其下檔案、`site/` 排除正確、
  首頁清單連結正確、根發佈不受影響
- 修過一個真 bug：`collectFiles` 進入點忘記從 `walk(root)` 換成 `walk(srcNode)`（e2e 抓到）
- 修站內連結：`rewriteMdLinks` 把相對 `.md` 連結改寫成 `.html`（錨點／query 保留，絕對 URL 不動），
  接在 render 後、消毒前
- 站點導覽只顯示第一層：`buildNavTree`（根檔案直列＋子目錄收合成 details，預設收起）
- 後改為**取消左側欄**：`buildNavTree` 刪除；內頁頂部麵包屑（⌂ 首頁／上層目錄可點），
  每個子目錄自動產生 `index.html`（直屬頁面＋子目錄清單）當上一層落點
- 發佈鈕旁加「檢視網站」：從本機 git remote 推算 `https://<owner>.github.io/<repo>/` 另開分頁；
  非 git／非 GitHub 就狀態列說明（自架主機請直接開該網址）
- 後拆成兩顆鈕：「檢視 local 網站」「檢視 GitHub 網站」（開 Pages 網址）
- 「檢視 local」上線又移除：blob overlay 方案問題太多（快照過期、中文 href 編碼查表），
  整組刪除（`buildLocalPreview`／`decodeRel`／`resolveSiteRel`／overlay UI＋CSS），
  只留「檢視 GitHub 網站」。本地看站改用：發佈後到 Finder 雙擊 `site/index.html`，
  或相容模式下載 zip 解壓看。
  背景：瀏覽器禁止 http 網頁直接開 `file://`，且拿不到真實磁碟路徑，拼不出 `file://…`；
  下載 zip 方案被打槍後改此版。`downloadSiteZip` 保留 `includeWorkflow` 參數（fallback 發佈用）。
- 修中文檔名點了空白頁：`href` 內中文被 markdown-it percent-encode（如 `%E5%90%91…`），
  blob 對照表是原文檔名，查表失敗連結沒改寫，iframe 載入失敗即空白。
  解法 `decodeRel`（逐段 `decodeURIComponent`，失敗回原文）後再查表。Pages／file:// 不受影響
  （server／檔案系統會自己解碼，只有 blob 查表需要原文）。
- web／webview／vsix（3.42MB）全重建
