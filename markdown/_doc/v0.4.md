# MD Editor v0.4（基於 v0.3）

以 `.mdeditor.json`（`{ srcDir, siteDir, branch }`）取代所有 `prompt()`。

## 行為（現況）

- 「發佈靜態網站」站內表單：來源下拉（`/`＋遞迴子目錄清單）、輸出目錄（支援巢狀，
  先正規化，擋尾斜線／空段／`..`）、分支、記住核取，全程無 `prompt()`。
- 收集改「來源相對」前綴比對跳過輸出目錄；寫入前清空舊輸出；單檔失敗記下繼續，
  最後一次列出（修過 `Name is not allowed` 只報裸錯誤）。
- 站內 `.md` 連結改寫 `.html`（錨點／query 保留，絕對 URL 不動），render 後消毒前。
- 站點**無左側欄**：內頁頂部麵包屑（⌂ 首頁／上層目錄可點），每子目錄自動 `index.html`。
  （中間有過第一層樹狀版，已刪除。）
- 中文檔名要能點：發佈產物由 server／檔案系統解碼，沒問題。
- Action：官方 Pages workflow，`configure-pages` 加 `enablement: true`；
  若報 `Resource not accessible by integration`，需 admin 到 Settings → Pages 選 GitHub Actions 一次。
- 「檢視 GitHub 網站」：從 git remote 推算 Pages 網址另開。
  （「檢視 local」blob overlay 版上線又移除：快照過期、中文 href 編碼查表問題；本地改 Finder 雙擊 `site/index.html`。）
- 預覽窗連結**全禁點**（`pointer-events: none`，防誤點跳頁），顏色淺藍 `#58a6ff` 區分。
- 新增檔案／資料夾、重新命名、刪除、關分頁：自繪對話框；檔名擋斜線與 `.`／`..`。
