# MD Editor v0.1

日期：2026-09-21。定位：只管「顯示跟 GitHub 一樣」，不管 repo；git/push 在 VSCode 自己做。

## 內容物

```
packages/core/              # renderer / sanitize / 獨立 HTML 匯出 + 測試 + 全語法範例
apps/web/                   # Vite 純靜態站：類 VSCode 工作區（dist/ 單一 index.html）
  src/fs.js                 # 資料夾層：File System Access（Chromium 可寫回）＋ webkitdirectory fallback
  src/main.js               # 檔案樹＋分頁＋dirty＋Ctrl+S＋新增/刪除/重新命名＋md 檢視切換
  src/editor.js             # CodeMirror 6（單一實例隨分頁切換內容）
  src/preview.js            # 即時預覽（core renderer＋mermaid＋DOMPurify）
extensions/vscode-md-gh/    # 插件：側邊預覽＋匯出獨立 HTML（md-gh.vsix）
server.sh                   # 本機預覽 dist/
```

## 功能

- 開啟本機資料夾 → 檔案樹（懶載入子目錄、圖示、作用中高亮、dirty 圓點）
- 分頁編輯，`Ctrl+S` 儲存（Chromium 寫回磁碟；Firefox/Safari 降級為下載存檔）
- `.md` 分頁右側即時預覽，編輯／並排／預覽可切
- 右鍵檔名重新命名（檔案）／刪除；新增檔案／資料夾；二進位檔阻擋開啟
- 匯出獨立 `.html`（自含樣式＋mermaid＋TeX，放任何靜態主機）
- 未存檔關閉分頁確認＋`beforeunload` 保護；terminal 未實作

## 顯示一致性（與 github.com 對齊）

GFM（table/task/strike/autolink/footnote/emoji/heading-id）＋ Alert 含標題列 ＋
` ```mermaid ` ＋ TeX（`$`/`$$`/` ```math `，KaTeX）＋ code 高亮。
code 區塊內的 `$` 不當數學；`{#id}` 等 GitHub 不支援語法保持字面。

## 已知簡化／限制

- 資料夾重新命名未做；樹右鍵用 `prompt()` 陽春選單
- 縮排式 code block 內的 `$` 仍可能被當數學（fenced 不受影響）
- Data URL 圖片在 github.com 不會顯示（僅本站預覽／匯出可用）
- 匯出的 `.html` 需連網載 CDN（mermaid/KaTeX/github-markdown-css）
