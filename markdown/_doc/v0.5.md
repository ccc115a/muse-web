# MD Editor v0.5（基於 v0.4）

頂欄按鈕太多，改成 VSCode 式下拉選單列。

## 變更

```
apps/web/index.html   # 按鈕列 → nav#menubar（檔案／檢視／專案／發佈），品項沿用舊 id
apps/web/src/menu.js  # 新增：點標題開、hover 切換、Esc／外點關、選後自動關
apps/web/src/style.css # 選單樣式（標題裸鈕、下拉卡片、kbd、分隔線、disabled）
apps/web/src/main.js  # initMenu()；#md-views 改 #menu-view＋syncViewMenu（非 md 分頁時禁用）
```

## 行為

- 檔案：開啟資料夾／新增檔案／新增資料夾／——／儲存 Ctrl+S／匯出 .html
- 檢視：編輯／並排／預覽（粗體表作用中；非 md 分頁整組 disabled）
- 專案：專案資訊／專案設定
- 發佈：發佈靜態網站／檢視 GitHub 網站
- 既有接線不動（品項 id 沿用）；`Ctrl+S` 照走；modal 的 Esc 與選單 Esc 互不干擾。
